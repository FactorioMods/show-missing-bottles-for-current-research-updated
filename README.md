# Show missing bottles for current research: Updated

Displays missing science packs beneath the current research, helping identify which supplies are holding up laboratory work.

This fork supports Factorio 2.1.24 and continuing games that used the original research display. The display does not locate individual labs or exclude every lab that cannot perform the selected research.

Requires Factorio 2.1.24 or later. Disable `show-missing-bottles-for-current-research` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.
